# Soil-Quality-Prediction-Analysis
The project uses machine learning for targeted soil quality prediction.It classifies soil as 'Good,' 'Moderate,' or 'Poor' using environmental and soil data.Helps farmers make better crop decisions and optimize yield. Promotes sustainable agriculture benefiting the economy and the environment.
